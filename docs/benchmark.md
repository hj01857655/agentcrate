# AgentCrate Benchmark 指标定义

> 原则：所有数字可复现（脚本入库），所有开销相对「直连」计量。

## 指标

| 指标 | 定义 | 目标 |
|---|---|---|
| gateway overhead P50/P99 | 网关层新增延迟（不含工具执行） | P99 < 5ms |
| trace overhead | 开启 OTel 相对关闭的延迟增量 | < 10% |
| sandbox 冷启动 / 热启动 | 容器创建到首字节 vs 池化复用 | 冷 < 800ms，热 < 50ms |
| 吞吐 | 单网关实例并发 tools/call RPS（mock 工具） | 公布实测曲线 |
| 台账精度 | ledger 合计 vs 上游账单（mock 计费器） | 误差 < 1% |
| 资源占用 | 网关空载 RSS / 每 1k 并发增量 | 公布实测 |

## 方法论

- mock 工具：可控延迟/字芔回显，隔离网络与磁盘噪声
- 负载：固定 seed 的合成调用序列（真实工具调用分布另录）
- 每次 publish 附带：机器规格、容器版本、原始数据 CSV、复现命令
- 超时取消的归账：上游已计费部分必须入台账，标记 `partial:true`
